# maze-generator

[![Live Demo](https://img.shields.io/badge/🚀_Live_Demo-Visit-blue?style=for-the-badge)](https://mayank-dev-15.github.io/maze-generator)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
![Language](https://img.shields.io/badge/Language-HTML/CSS/JS-green)

Procedural maze generator with 5 generation algorithms and 5 pathfinding algorithms, animated visualization, and side-by-side comparison.

`algorithms` `maze` `pathfinding` `canvas` `visualization`

---

## ✨ Features

- 5 maze generation algorithms (Recursive Backtracker, Prim's, Kruskal's, Eller's, Binary Tree)
- 5 pathfinding algorithms (A*, Dijkstra's, BFS, DFS, Greedy Best-First)
- Animated algorithm visualization
- Adjustable maze size (5-101)
- Step-by-step mode for learning
- Side-by-side algorithm comparison
- Statistics: nodes explored, path length, time taken
- Export maze as PNG
- Dark theme with neon cyan/pink accents


---

## 💡 Usage

- Select a generation algorithm and click Generate
- Select a pathfinding algorithm and click Solve
- Use Step to advance one frame at a time
- Toggle Compare for side-by-side mode
- Adjust size and speed with sliders
