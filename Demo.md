## About

**maze-generator** is a procedural maze generator with pathfinding.

### Key Features

- 5 maze generation algorithms (Recursive Backtracker, Prim's, Kruskal's, Eller's, Binary Tree)
- 5 pathfinding algorithms (A*, Dijkstra's, BFS, DFS, Greedy Best-First)
- Animated algorithm visualization
- Adjustable maze size (5-101)
- Step-by-step mode
- Side-by-side algorithm comparison
- Stats: nodes explored, path length, time
- Export maze as PNG
- Dark theme with neon cyan/pink accents

## Controls & Usage

| Control | Action |
|---------|--------|
| `Generate` | Create new maze |
| `Solve` | Run pathfinder |
| `Step` | Advance one step |
| `Compare` | Side-by-side mode |
| `Size slider` | Adjust dimensions |
| `Speed slider` | Animation speed |
